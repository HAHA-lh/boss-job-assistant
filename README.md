# 求职匹配助手

一个仅供个人本机使用的 Chrome / Edge Manifest V3 扩展。它在本地解析简历、分析当前可见或手工粘贴的岗位、解释匹配原因，并生成需要由用户自行核对和发送的招呼语草稿。

源码版本和安装包发布在 [GitHub Releases](https://github.com/HAHA-lh/boss-job-assistant/releases)。每次提交会自动运行测试和构建，版本标签会自动生成扩展 ZIP。

## 安装构建产物

v0.1.5 兼容当前 `/web/geek/jobs` 可见岗位列表结构，并保留标签式多项输入以及 Service Worker、侧边栏和 PDF Worker 修复。

1. 解压 `boss-job-assistant-extension-v0.1.5.zip`，或直接使用交付目录中的 v0.1.5 扩展文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的扩展目录。
5. 固定“求职匹配助手”，点击图标打开侧边栏。

如果安装过旧版并需要保留扩展本地数据，请先关闭侧边栏，清空原扩展目录中的旧文件，再把完整的 v0.1.5 文件复制到同一个目录，最后在扩展管理页点击“重新加载”。不要只覆盖部分文件。若改用新的目录重新安装，Chrome 可能把它识别为新的扩展实例。

## 首次使用

1. 在“简历”页导入文字型 PDF / DOCX，或粘贴简历文本。
2. 校对目标岗位、技能、工作年限、学历、城市、薪资和经历亮点后保存。
3. 在“设置”中调整硬条件、权重、阈值、每日上限和提醒时间。
4. 未取得页面读取许可时，在“今日匹配”中粘贴岗位文本，多个岗位用单独一行 `---` 分隔。
5. 如已确认平台许可或当前规则允许，可勾选授权声明；在 BOSS 直聘岗位列表页点击“扫描本页”，并在浏览器提示中授予 `www.zhipin.com` 站点权限。
6. 勾选高匹配岗位并“批准已选”。逐条点击“复制并打开岗位”，自行粘贴、核对和发送。
7. 发送或收到回复后手动标记，数据会进入本地看板。

## 明确不包含

- 不后台访问或抓取网站，不自动翻页。
- 不读取 Cookie、账号密码、简历收发记录或聊天内容。
- 不自动点击开聊、填充输入框或发送消息。
- 不处理验证码，不包含风控规避或模拟真人逻辑。
- 不上传简历、岗位、统计或遥测数据。

页面扫描功能仍可能受到平台规则约束。启用前请复核 [BOSS 直聘当前协议](https://about.zhipin.com/agreement)；没有明确许可时使用粘贴模式。

## 数据和隐私

- PDF / DOCX 只在当前扩展页面内解析，原文件不保存。
- 手机号、邮箱、身份证号和常见微信号格式会在结构化前移除。
- 结构化简历和设置存放于 `chrome.storage.local`。
- 岗位与活动记录存放于扩展自己的 IndexedDB。
- 默认岗位去重 30 天、活动保留 90 天，可修改。
- 设置页支持 CSV 导出和清空全部本地数据。

## 源码开发

要求 Node.js 20+。

```powershell
npm install
npm test
npm run build
```

构建结果位于 `dist/`。自动化测试使用脱敏的本地 HTML 固件，不访问生产网站。

版本发布和 Chrome 更新方式见 [UPDATING.md](UPDATING.md)。

## 已知限制

- 扫描件、图片型或加密 PDF 不支持 OCR，请改用 DOCX 或粘贴文本。
- 页面扫描依赖网站可见 DOM；网站改版后会安全停止并提示更新适配器。
- 规则匹配不等于招聘建议，评分和话术必须由用户最终判断。
- 浏览器休眠时提醒不会唤醒设备，恢复后由浏览器处理错过的提醒。
